# Tool Tracer – Tool Traceability Software

This repository serves as supplementary material for the Master’s thesis titled **"Development and Implementation of a Tool Traceability System for an Aviation Maintenance, Repair, and Overhaul Organisation"**. 

It features **Tool Tracer**, a dedicated tool traceability software designed to log check-in and check-out transactions in real time, minimize non-productive tool search times, enforce individual tool accountability, and mitigate Foreign Object Debris/Damage (FOD) risks in high-consequence maintenance environments.

## Repository Structure

The repository is organized into two primary components:

### 1. Source Code (Tool Tracer - Source Code.zip)
* Contains the full Python source code for the **Tool Tracer** software.
* Includes all necessary assets, system images, and database dependencies.

### 2. Executable Package (Tool Tracer 1.06 - Executable File.zip)
* Contains the compiled, standalone executable file (`.exe`) of **Tool Tracer** generated using PyInstaller.
* Includes all necessary assets, system images, and database dependencies.
* Designed to run directly on a target Windows terminal without requiring a local Python environment.
